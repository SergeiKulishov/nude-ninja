# План публичного релиза FullBlur Filter (OBS plugin)

Цель: публичный релиз плагина `fullblur-filter` для OBS Studio 32.x (Windows x64)
с установщиком, CI-сборкой и публикацией в каталоге плагинов OBS.

Легенда статусов: `[ ]` не начато, `[~]` в работе, `[x]` готово.

  - [x] до окончания скачивания фильтр работает как passthrough + статус в AI stats
        ("Model downloading…");
  - [x] удалить `data/models/320n.onnx` из пакета и из install.bat.

## Риски и смягчения

| Риск | Смягчение |
|---|---|
| GPL-2.0 vs GPL-3.0 (модель NudeNet) | First-run download вместо бандлинга (фаза 0.2) |
| SmartScreen ругается на installer | SignPath/OV-подпись позже; инструкция в README |
| Слом ABI на новой версии OBS | CI-матрица, быстрые пересборки по выходу OBS |
| Ложные срабатывания у пользователей | FAQ по confidence/классам, пресеты, issue-шаблон |
| VRAM на слабых GPU | Рекомендации в FAQ (Delay↓), VRAM-оптимизация в 1.x |
