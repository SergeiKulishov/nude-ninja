FullBlur Filter 0.9.0 beta для OBS Studio 32.x (Windows x64)
=============================================================

FullBlur — фильтр источника OBS, который задерживает видео и аудио,
запускает NSFW-детекцию (NudeNet ONNX) и пикселизирует/блюрит кадр
при необходимости. Сценарий использования: стрим фильмов/контента,
где неожиданные взрослые кадры не должны попасть в эфир.

Требования
------------
- OBS Studio 32.x 64-bit
- Windows 10/11 x64
- Видеокарта с DirectML настоятельно рекомендуется (ONNX Runtime
  по умолчанию использует DirectML; инференс на CPU очень медленный)

Установка вручную из ZIP
------------------------
1. Закройте OBS Studio.
2. Скопируйте содержимое архива в папку OBS,
   например C:\Program Files\obs-studio
   - obs-plugins\64bit\*.dll → OBS\obs-plugins\64bit\
   - data\obs-plugins\fullblur-filter\ → OBS\data\obs-plugins\fullblur-filter\
3. Запустите OBS, добавьте фильтр «FullBlur Filter» к источнику.
4. При первом включении фильтр скачает модель детекции
   (~12 МБ для 320n, ~100 МБ для 640m) в:
      %APPDATA%\fullblur-filter\models\
   В строке «AI stats» будет виден прогресс загрузки.

Удаление
--------
- Удалите fullblur-filter.dll, onnxruntime.dll,
  onnxruntime_providers_shared.dll и DirectML.dll из
  OBS\obs-plugins\64bit\
- Удалите папку OBS\data\obs-plugins\fullblur-filter\

Быстрые настройки для первого теста
-----------------------------------
- Задержка: 300–500 мс
- AI detail: Single или 2x2
- Process every: 3 или 4
- AI model: 320n (быстрее) / 640m (точнее, нужна GPU)

Отказ от ответственности
------------------------
FullBlur — помощник модерации, а не 100% гарантия. Стример несёт
полную ответственность за транслируемый контент. Всегда используйте
совместно с человеческим контролем и платформенной задержкой.

Сторонние лицензии
------------------
THIRD_PARTY_LICENSES\ содержит лицензии ONNX Runtime и DirectML (MIT).
Модель NudeNet загружается отдельно во время работы.
