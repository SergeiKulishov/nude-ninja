# FullBlur Filter (OBS plugin)

OBS-фильтр для стримеров: задерживает видео и звук источника, прогоняет кадры
через NSFW-детектор (NudeNet / ONNX Runtime + DirectML) и при обнаружении
наготы блюрит кадр (целиком или только найденные области) до того, как он
уйдёт в стрим.

## Disclaimer

FullBlur — это **инструмент помощи модерации**, а не гарантия фильтрации.
Детектор может пропускать запрещённый контент (ложные отрицания) и
срабатывать на безобидный (ложные положения). **Ответственность за
tранслируемый контент полностью лежит на стримере.** Используйте фильтр как
dополнительный уровень защиты, а не как единственный.

## Модель NudeNet (скачивание при первом запуске)

Модель `320n.onnx` (~12 МБ) **не входит в пакет** (репозиторий NudeNet —
GPL-3.0, несовместим с GPL-2.0 libobs при бандлинге). При первом добавлении
фильтра модель автоматически скачивается с HuggingFace-зеркала в
`%APPDATA%\fullblur-filter\models\` (проверка SHA-256). Пока идёт скачивание,
фильтр работает как passthrough, а в поле **AI stats** виден прогресс.
Без интернета модель можно положить вручную в ту же папку.

## Установка

### Установщик (рекомендуется)

1. Закройте OBS Studio.
2. Запустите `fullblur-filter-0.9.0-setup.exe` от имени администратора.
3. Запустите OBS. Правый клик по источнику → **Filters** → **+** → **FullBlur**.

### Ручная установка из ZIP

1. Закройте OBS Studio.
2. Скопируйте содержимое архива в папку OBS, например
   `C:\Program Files\obs-studio`:
   - `obs-plugins\64bit\*.dll` → `OBS\obs-plugins\64bit\`
   - `data\obs-plugins\fullblur-filter\` → `OBS\data\obs-plugins\fullblur-filter\`
3. Запустите OBS и добавьте фильтр.

Требования: OBS Studio 32.x, Windows 10/11 x64. GPU не обязателен
(будет CPU-инференс), но с DirectML нагрузка заметно ниже.

## Звук (важно!)

Фильтр задерживает только звук, проходящий через сам источник:

- **Вариант А (рекомендуется):** в свойствах источника (Game/Window Capture)
  включите **Capture audio**, а в Audio Mixer **заглушите Desktop Audio**.
- **Вариант Б:** добавьте источник *Application Audio Capture* и повесьте
  фильтр FullBlur и на него (задержит только звук на ту же величину).

Локально слышать задержанный звук: *Edit → Advanced Audio Properties →
Audio Monitoring → Monitor and Output*.

## Настройки

| Параметр | Описание | Default |
|---|---|---|
| Delay | Задержка A/V (время на анализ AI) | 2.0 с |
| Blur strength | Сила пикселизации | 14 |
| Blur mode | `Full frame` / `Detected areas` (точечный блюр) | Full frame |
| Area margin | Расширение областей (компенсация движения) | 1.5 |
| AI confidence | Порог детекции (эффективный минимум 0.25) | 0.2 |
| Hold blur | Удержание блюра после последнего NSFW | 2.0 с |
| Process every Nth | Анализировать каждый N-й кадр | 2 |
| AI detail | Сетка тайлов: `Single` (1 проход), `2x2`, `3x3` — ловит мелкие объекты. К сетке всегда добавляется полнокадровый проход, тайлы перекрываются на 12% | 2x2 |
| AI model | `320n` — быстрая (CPU/DirectML), `640m` — точная, вход 640×640, **только GPU** (YOLOv8m, ~99 МБ, скачивается при выборе). Для 640m рекомендуется Single/2x2 + Process every 3–4 | 320n |
| Temporal voting | Голосование по времени: `2 of 3` — блюр при NSFW в 2 из 3 последних анализов тайла (убирает ложные вспышки и мерцание) | 2 of 3 |
| Strong hit bypass | Уверенное NSFW (score ≥ порога) блюрит мгновенно, минуя голосование — включая однокадровые вспышки | on, 0.5 |
| Force blur | Принудительный блюр (тест) | off |
| Classes preset | Пресеты классов: `Recommended` / `Exposed only` / `All 18` / `Custom` | Recommended |
| Blur classes | Группа чекбоксов — 18 классов NudeNet, выбор мышкой | 9 классов |
| Blur unverified frames | Fail-safe: блюрить кадры, которые AI не успел проверить | off |
| Blur now! | Panic-кнопка: блюр на N секунд немедленно | 10 с |
| AI stats | Провайдер, скорость inference, счётчики | — |

Замечания:

- Буфер задержки хранит кадры в VRAM: ~0.5 ГБ на секунду задержки при
  1080p60. При нехватке памяти уменьшите Delay.
- **AI detail и нагрузка.** Каждый тайл — отдельный инференс (~5–15 мс на
  DirectML). При 60 fps: `2x2` ставьте Process every = 2–4 (60–120
  инференсов/сек), `3x3` — 6–10 (54–90/сек). Если в AI stats растёт
  `dropped` — AI не успевает: увеличьте Process every или снизьте деталь.
  Режим `3x3` ловит объекты размером от ~3–4% кадра.
- Режим `Detected areas` оставляет стрим смотрибельным, но при очень
  быстром движении объекта рамка может на несколько кадров отставать —
  увеличьте Area margin или используйте `Full frame` для 100% гарантии.
- Фильтр ставится на каждый источник отдельно (или на группу/сцену).

## Сборка из исходников

Требуется: Visual Studio 2022/2026 (C++), CMake 3.28+, интернет
(при первой конфигурации скачиваются obs-studio 32.1.2, obs-deps,
ONNX Runtime 1.22.1, DirectML 1.15.4).

```bat
cmake --preset windows-x64
cmake --build --preset windows-x64
install.bat   :: от администратора
```

## Архитектура

```
источник → filter:
  video_render: захват кадра (texrender) → GPU ring-buffer (delay)
              → каждый N-й кадр: атлас тайлов (по 320x320 ячейке)
                → staging → нарезка → AI worker (FIFO 32, drop-oldest)
              → вывод кадра старше delay; блюр по verdict+bbox / hold / panic
  filter_audio: FIFO на ту же задержку (таймстемпы OBS → sync)
AI worker (поток): ONNX Runtime (DirectML→CPU fallback), NudeNet 320n,
                    top-8 bbox/тайл, агрегация OR по тайлам кадра
```

Файлы: `src/fullblur-filter.c` — фильтр (задержка, блюр, UI),
`src/ai-worker.cpp` — поток инференса, `src/model-download.cpp` — докачка
модели `320n.onnx` при первом запуске.
